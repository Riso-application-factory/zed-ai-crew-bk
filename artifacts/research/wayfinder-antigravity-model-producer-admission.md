# Antigravity model producer admission

Status: research decision for [#52](https://github.com/Riso-application-factory/zed-ai-crew/issues/52). Source investigation is complete within the inventory below; runtime compatibility and confinement are awaiting a bounded prototype. This is a planning artifact, not a usable Increment or production approval.

## Answer and scope

**Investigate an epoch-specific capability in the existing gateway URL before considering a new integration.** The public SDK has configurable model HTTP headers and API keys, but no inspected first-party source establishes that installed ACP 1.3.0 exposes those SDK fields. The installed fixture already uses `AGY_LLM_GATEWAY_URL`; preserving an opaque path prefix through that override is a precise compatibility hypothesis, not a documented ACP authentication feature. Do not invent header settings, replace ACP with the SDK, or adopt a private kernel interface to make the gap disappear.

A capability authenticates possession. It identifies the admitted producer only insofar as an independently enforced boundary prevents every other in-scope actor from obtaining or using it. A live native process graph, HTTP `sessionId`, loopback address, random port or public correlation header does not supply that proof. Even a correctly scoped URL credential does not reject a different process intentionally given the current credential. That control must be reported honestly. The destination's actual same-user threat scope cannot silently be reduced to make a fixture pass.

Entry evidence is the [actual separate-sender counterexample](https://github.com/Riso-application-factory/zed-ai-crew/issues/18#issuecomment-6167187251): six unrelated public requests forwarded, two poisoned-epoch requests denied. The earlier [distinct receiver facts](https://github.com/Riso-application-factory/zed-ai-crew/issues/50#issuecomment-6166186756) and [one-incarnation fences](https://github.com/Riso-application-factory/zed-ai-crew/issues/51#issuecomment-6166718735) remain bounded resolved. No old helper grant or historical fact becomes fresh authority through a transport change.

## Smallest alternatives and rationale

| Alternative | Decision for this session | Return condition |
| --- | --- | --- |
| Existing URL override with epoch capability and explicit custody boundary | **Investigate**, using public fixtures and unchanged ACP. Smallest available measured configuration surface; runtime prefix support unknown. | Compatibility result and exposure/actor evidence, including failed controls, return to #18. A bearer-only pass cannot complete producer admission. |
| Public SDK model headers/key or owned callback/transport | Keep as a source-supported embedding alternative where actually exposed. No inspected callback was established that replaces installed ACP's model transport. | Requires an actual supported ACP join or an explicit product/integration decision; do not substitute SDK for mandatory ACP. |
| Reachability isolation without a credential | Conditional boundary alternative; insufficient in the existing broadly reachable loopback fixture. | Prove every in-scope nonproducer cannot reach ingress, cannot relay through native/control/host tools, and cannot obtain inherited sockets. State the actor scope before drawing a conclusion. |
| Unix peer credential boundary | Conditional if a supported native transport or enforceable authenticated incoming leg becomes available. | Exact socket sender/incarnation and FD inheritance/delegation/PID reuse/error/revocation evidence. An outgoing relay identity is insufficient. |
| Private TCP PID lookup or periodic ps/lsof | Retain as diagnostic source leads only. | No supported stable authorization contract established; no implementation is authorized by this note. |

A capability must be issued after current admission, unique to one live owner epoch and retired when owner/native/watch/history validity is lost. It must not appear in worker argv/env, readable configuration/logs/model history, procargs exposure, inherited FDs, or a reusable control call available to another actor. Do not forward it to the synthetic upstream or a real provider. Graph checks and #50 history validation still run before forwarding; cached keepalive connections are not permanent authority. Survivor ownership and fail-closed loss handling remain necessary. These are proposed composition requirements, not measured facts.

## Next bounded decision and observable controls

Precisely test whether the existing installed URL override preserves an opaque per-epoch prefix to the owned gateway, and what producer claim can be supported under the **actual** effective profiles. Use one public fixed incarnation, then retire/quiesce and repeat with a fresh epoch. Never guess an undocumented header/env schema or mutate the proprietary adapter.

1. Actual unchanged ACP/native positive: capture HTTP path before any body forwarding, exact body marker, admitted graph and upstream observation. Prefix ignored/rejected/stripped must produce a retained incompatibility result; do not replace the adapter or silently weaken the check.
2. Separate actor with no/foreign/stale prefix and matching/foreign/missing service fields: independent PID/socket evidence plus no upstream marker. Correct service data alone must not authorize it.
3. Separate actor intentionally given the current prefix: distinguish bearer acceptance from rejection caused by a separate enforced boundary. Accepted current capability is a scope limit, not PID authentication success.
4. Actual custody controls: worker clean env/argv/FDs, same-user procargs/environment reads, configuration/state/log/model-history visibility and gateway reachability under recorded effective policies. Distinguish confined worker, same-policy unrelated actor and unconfined same-user actor. Retired public probe tokens can be archived; never publish a live credential.
5. Current versus retired epoch replay and keepalive; actual owner/controller loss; poison/lost watch/unknown-native denials; old graph quiescence before fresh positive. Preserve independent immutable historical facts, no helper replay and no old grant revival. If composition is not reached, report exactly which controls did not run.

Completion of that prototype is a supported bounded answer, including a precise incompatibility or custody counterexample. It is not a demand that every candidate must pass, nor permission to choose a weaker threat scope. Missing production topology, packaging/signing, private preparation/full-policy/provenance, durable survivor recovery, arbitrary descendants and real provider comprehension remain #18 fog; active cancellation/resume remains #20.
